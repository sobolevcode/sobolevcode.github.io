02 / Featured project

ProxyTune

v2.4.0

LG webOS 4.0+  ·  ROOT  ·  JSON  ·  AWG

Менеджер сетевых конфигураций и подписок для телевизоров LG Smart TV с удобным управлением со смартфона.

  • Управление сетевыми профилями
  • Поддержка JSON-профилей и подписок
  • Поддержка (AWG)
  • Управление с мобильного устройства

Требования: webOS 4.0+ и Root (проверить совместимость). Рекомендуется отключить IPv6 и указать DNS 1.1.1.1.
